# Proyectos de JavaScript (Frontend & UI)

Repositorio que recopila una serie de proyectos prácticos y dinámicos desarrollados con JavaScript vanilla, HTML5 y CSS3, enfocados en afianzar la lógica de programación, la manipulación del DOM y el diseño de interfaces interactivas.

## Tecnologías Utilizadas
* **JavaScript (ES6+)**: Lógica de programación, eventos, manipulación asíncrona y del DOM.
* **HTML5**: Estructuración semántica de componentes web.
* **CSS3**: Estilos avanzados, diseño responsivo y maquetación (Flexbox / Grid).

---

## Contenido del Repositorio

A continuación se detallan los proyectos incluidos:

1. **01-CalculadoraAmor**: Aplicación interactiva de lógica matemática básica y manipulación de eventos.
2. **02-BMI**: Calculadora de Índice de Masa Corporal con validación de datos de entrada del usuario.
3. **03-Todo**: Gestor de tareas dinámico para agregar, marcar como completadas y eliminar elementos.
4. **04-RGB**: Generador de colores dinámicos en formato RGB mediante manipulación de inputs y estilos en tiempo real.
5. **05-Editor**: Herramienta interactiva de edición visual básica de texto/elementos en pantalla.
6. **06-Netflix**: Interfaz inspirada en plataforma de streaming enfocada en la maquetación y diseño responsivo.
7. **07-Reproductor**: Reproductor multimedia interactivo con controles personalizados en JavaScript.
8. **08-Agenda**: Sistema simple de organización de notas y eventos locales.
9. **09-Juego**: Aplicación lúdica orientada al desarrollo de lógica de control y estados.
10. **10-Perfil**: Componente de tarjeta de perfil de usuario con diseño moderno y adaptativo.
